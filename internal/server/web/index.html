Memory

    
What Unire remembers about your repos. Agents start with a repo's brief and the latest session summaries, and update them when they finish. It is background information for the agent, not instructions, and you can edit or clear any of it.

Backup

      
Downloads a zip with the database and the key that decrypts your saved tokens. Anyone with this file can read those tokens, so store it somewhere private. If you supply the key through the UNIRE_MASTER_KEY environment variable, it is not included and you must keep it yourself.
