# Contributing to Unire

Thanks for your interest. Unire is early, so the best way to help right now is to read [SPEC.md](SPEC.md) and open an issue with feedback or ideas.

## Contributor License Agreement

Unire is released under the AGPL-3.0, and the project owner also offers commercial licenses. To make that possible, every contribution must be covered by a contributor license agreement (CLA) that lets the project owner distribute your contribution under the AGPL and under other licenses.

The CLA text and signing process are not set up yet. Until they are, **please open an issue to discuss before sending a pull request; pull requests will not be merged until the CLA is in place.**

## Plugin contributions

Git providers, agent adapters and preview providers are each meant to be a single file implementing a small interface, with a shared conformance test suite. The interfaces are described in the spec and will be documented here once the core exists.

## Security

Please do not open public issues for security problems. Contact the repository owner privately.
