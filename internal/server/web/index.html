Settings

Unire has one owner: you. Anyone else who wants to use it runs their own copy.

Limits

Stop runaway runs and keep the database and disk from growing for ever.

A run that goes over its time is stopped and marked failed. Answers, questions and what was pushed are always kept; a removed workspace is cloned again from its pushed branch when you reply.

Sandbox

How each agent's disposable container runs.

Sign in to the agents on the Agents tab. The logins are saved in the login volume above.

Network access

What a sandbox can reach.

Used in Internet only and Agent only mode, on top of the internet (or the agent's own service) and your git servers. A host name, an address or a range, optionally with a port. A chat's git servers are always allowed.

Backup

Everything needed to restore Unire.

Downloads a zip with the database and the key that decrypts your saved tokens. Anyone with this file can read those tokens, so store it somewhere private. If you supply the key through the UNIRE_MASTER_KEY environment variable, it is not included and you must keep it yourself.
